**New files:**
- `lab/cite.py` — `lab cite <unit> <key>` prints the raw value from values.tsv, one line, no decoration. Exit 0 on success, 1 if the key does not exist (lists available keys on stderr), 2 if the unit cannot be loaded.
- `lab/brief.py` — `lab brief <unit>` generates a fenced brief block carrying keys and unit ids for an agent prompt. The brief lists key NAMES only; no raw numeric values cross the boundary. Contains: unit id, title, type, date, sealed status, follows chain, refs, agents, values.tsv key names, file listing, unit path.
- `lab/report.py` — `lab report <unit>` generates a report block tagged with `[<id>]` for grep. Contains: unit identity, gate results from lab_run JSONs (exit code, wall time), values summary with lab check output, agents, refs.
