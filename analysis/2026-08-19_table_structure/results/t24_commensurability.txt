4. THE SAME FACT WITH THE OPPOSITE SIGN - t6_multirate
   a single ladder at base b aliases every zero above pi/ln b, and
   returns a COMB of peaks at spacing 2*pi/ln b, all of equal height:
      base 2: Nyquist pi/ln b =  4.532   comb spacing 2*pi/ln b = 9.0647
      base 3: Nyquist pi/ln b =  2.860   comb spacing 2*pi/ln b = 5.7192
   measured, base 2 alone: five peaks at 8.898 17.965 27.358 36.425
   45.156, every one at variance explained 0.486 (results/t6_multirate.txt)
   gaps 9.067 9.393 9.067 8.731 against the stated 9.0647
   pooling base 2 with base 3 breaks the tie EXACTLY BECAUSE
   ln3/ln2 is irrational - the two combs share no tooth but the first.

5. THE SAME FACT AS A CENSORING NOTE - The-Four-Zeros C5
   base 2 depth d spans a window of ratio 2^(d+1).  another base b
   reaches that window at depth log(2^(d+1))/log b - 1, integer or not:
      (20,6)'s window has ratio 2^7 = 128:
         base 3: depth   3.417   not an integer
         base 4: depth   2.500   not an integer
         base 5: depth   2.015   not an integer
         base 6: depth   1.708   not an integer
         base 7: depth   1.493   not an integer
         base 9: depth   1.208   not an integer
      (8,3)'s window has ratio 2^4 = 16:
         base 3: depth   1.524   not an integer
         base 4: depth   1.000   INTEGER
         base 5: depth   0.723   not an integer
         base 6: depth   0.547   not an integer
         base 7: depth   0.425   not an integer
         base 9: depth   0.262   not an integer
   (8,3)'s window 2^4 IS reached by base 4 at depth 1, since
   log2/log4 = 1/2 exactly.  (20,6)'s 2^7 is reached by no integer
   base but 2, because 7 is prime.  That is the whole difference
   between the two deep zeros.
   7 is prime, so 2^7 is reached by no integer base but 2 - which is
   Zeros.window_exclusive_of_prime_exponent, proved.
