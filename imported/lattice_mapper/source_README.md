# Difference Tables — Organized by Seed Count

All silenced tables follow the convention: **regime 2 is silent** (pi(2) = 0).
The prime 2 is not counted — it is the scaffold of the number line.

## Folders

### `32bit/`
Power-regime tables: A(n) = pi(b^n) - pi(b^(n-1)) for bases 2-9.
These are the original tables from the FPGA miner (32-bit seeds, 28 regimes max).
Also contains the 32-bit hex seed file (32 values of pi(2^n)).

**Note:** The 28-regime dyadic table here still uses the UNSILENCED convention
(A(1)=1, A(2)=1). It needs to be regenerated with A(1)=0, A(2)=0 to match
`difference_table.xlsx`. The triadic and higher base tables are unaffected
(regime 2 silencing only applies to base 2).

### `64bit/`
Integer-regime table: pi(n) for n = 1..64, with regime 2 silenced.
64-bit exact arithmetic, 32 depths. Silenced: pi(2) = 0.
Also contains `triadic_lattice_seeds_64bit_64.hex` — triadic seed file (64-bit).

### `128bit/`
Integer-regime table: pi(n) for n = 1..128, with regime 2 silenced.
64-bit exact arithmetic, 32 depths. Silenced: pi(2) = 0.

### `1000/`
Integer-regime table: pi(n) for n = 1..1000, with regime 2 silenced.
64-bit exact arithmetic, 17 depths. Silenced: pi(2) = 0.
3,521 zeros. Deepest: depth 19 (gap of 20 at regime 887).

### `2pow20/`
Full lattice lookup table: pi(n) for n = 1..2^20 (1,048,576 entries).
Both CSV (32MB) and binary (24MB) formats. These are the raw lookup tables
used by the FPGA/GPU mappers for fast prime-count retrieval.

### `archive_unsilenced/`
The original tables generated BEFORE the regime 2 silencing convention was applied.
Standard pi(n) with pi(2) = 1. Kept for comparison — the differences from regime 2
onward are identical, but regime 1's column differs by alternating (-1)^(d+1).

## Generator

All silenced tables are generated by:
    `lattice_mapper/dyadic_difference_table_64bit.py`

Usage:
    python3 dyadic_difference_table_64bit.py --seeds 64
    python3 dyadic_difference_table_64bit.py --seeds 128
    python3 dyadic_difference_table_64bit.py --seeds 1000 --depth 17

## The Convention

    Standard pi(n): pi(1)=0, pi(2)=1, pi(3)=2, pi(4)=2, pi(5)=3, ...
    Silenced pi(n): pi(1)=0, pi(2)=0, pi(3)=1, pi(4)=1, pi(5)=2, ...

The ground truth is `difference_table.xlsx` in the project root.
