# Unit format

A unit is a directory under `units/` with this shape:

    units/0305-fixed-window-Lc/
      unit.md          authored prose + YAML front matter
      question.md      the transcript bracket the question was posed in
      run/             the code, its results, its logs -- as produced
      values.tsv       GENERATED: key<TAB>value, one line per leaf
      UNIT.sha256      GENERATED: hash per file, plus a unit digest

## Front matter

The front matter is flat YAML between `---` delimiters. The parser
(`lab/unit.py`) accepts one `key: value` per line, where a value is a
bare scalar, a quoted scalar, `true`/`false`, or a flow list of bare
scalars. Every other shape is refused.

### Required fields

| field        | type         | meaning |
|---|---|---|
| `id`         | scalar       | 4-digit zero-padded sequence number |
| `date`       | scalar       | ISO date the unit was created |
| `type`       | scalar       | one of: `run`, `census`, `reconstruction` |
| `title`      | scalar       | slug from the directory name |
| `refs`       | flow list    | lean theorem paths (`lean/File.lean::name`) or `[none]` |
| `supersedes` | flow list    | unit ids this replaces, or `[]` |
| `sealed`     | bool         | `true` once the unit is immutable |

### Connection fields

These three fields carry the unit's place in the test series. The prose
and the links express the same connections independently. If they
disagree, the check catches it.

| field        | type         | meaning |
|---|---|---|
| `context`    | quoted scalar| one line: what the test does and what it connects to |
| `precedes`   | flow list    | unit ids this test feeds into |
| `follows`    | scalar       | the unit id this test follows in the chain |

`follows` already exists in the lab program and is validated by
`lab/check.py :: follows_problems()`. `context` and `precedes` are new.

### The cross-check

Every unit id in `precedes` and `follows` must appear somewhere in the
`context` prose. Every 4-digit id in the `context` prose must appear in
`precedes`, `follows`, `refs`, or `supersedes`. A mismatch is drift.

The check is the same principle as numbers in prose matching values.tsv:
redundancy is the detector. Two independent expressions of the same
fact, and disagreement between them is the finding.

Gate: `python3 utilities/check_unit_context.py <unit>` exits 0.

## question.md

The orchestrator writes this file. The porting agent leaves a
placeholder. Content comes from the chat transcript where the
orchestrator drafted it, the lab notebook, and CONTEXT.md.

question.md is a transcript bracket copied in verbatim, so its numbers
are quoted rather than claimed. `lab check` does not scan it.

## values.tsv

Generated by `lab values`. One `key<TAB>value` per line, one line per
leaf in the run's results JSON. The invariant is: every number in
unit.md's prose appears in this file.
