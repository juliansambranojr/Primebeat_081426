# Ontology

Topics every unit range is indexed by. **Add only:** a topic is never renamed or removed, so every range's index
keeps matching. A new topic gets a new line; a split topic keeps the old name and adds the parts.

| Topic | What it covers |
|---|---|
| `table` | The dyadic prime difference table itself: rows, depths, the four zeros, layout |
| `census` | Rows proved cell by cell from exact prime counts |
| `pi-list` | Exact π(2^m) in the kernel: sieves, Legendre, Meissel–Lehmer, the row build |
| `rh-proof` | The Lean RH proof and how the tree uses it (welds) |
| `route` | Error bounds from RH: explicit formula, zero count, transfer, route constants |
| `gate` | Main term against error at a cell: floors, prices, the depth and line theorems |
| `corner` | The deep corner: cells no error bound reaches |
| `harmonics` | The corner's structure from the zeros: comb, leaders, cancellation, phase, beats |
| `certificates` | Exact certificates for cells: congruences, weighted prime counts |
| `capstone` | The single statement assembling what is proved, and its open inputs |
| `novelty` | What is new against the literature and other formalizations |
| `method` | Process: welds, lost-factor decisions, archives, ontology |
