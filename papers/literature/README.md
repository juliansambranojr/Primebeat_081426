# Literature searches

Three literature searches run 2026-08-18 by three independent agents.
`litsearch_1_hinge.md` covers the Euler-factor symbol identity and its
Weil-weight counterpart. `litsearch_2_priority.md` asks whether the
iterated-difference table of pi(2^n) is a known object. `litsearch_3_annulus.md`
collects citations for the transform-radius criterion.

These files are AGENT OUTPUT, not verified prose. Every citation in them —
author, title, venue, year, arXiv id, theorem number, and any quoted
statement — should be checked against the primary source before it is relied
on or quoted in a paper. Treat an unchecked citation here as a lead, not a
fact. The files are kept verbatim, hedges and stated uncertainties included,
because the wording is part of the record.

All three searches share the same gaps. There was no MathSciNet access.
zbMATH returned HTTP 403 in two of the three. Google Scholar was not
reachable. The arXiv API searches metadata only, not full text, so a result
buried in a paper body would not have surfaced. Absence of a hit in these
files is therefore weak evidence of absence in the literature.
