**What was done.** Phase 8 added a quote gate Stop hook that enforces the
relay rule: every blockquote and fenced code block in an assistant message
must be an exact substring of something that appeared earlier in the
transcript.

**Created:**
- `utilities/hooks/check_quote_gate.py` (218 lines) -- reads the session
  transcript JSONL, builds a corpus from all prior text, extracts quoted
  material from the last assistant message, verifies each as an exact
  substring. Ellipsis splits into independently checked segments. Empty
  quotes skipped. `PB_NOQUOTE=1` env var bypasses. Parse errors fail open.
  Loop guard (`stop_hook_active`) lets second failures through.
- `tests/test_phase8.py` (15 tests) -- covers exact match, ellipsis
  splitting, empty-quote skipping, env-var bypass, loop-guard behavior,
  fenced-block extraction, and failure-mode cases.

  Stop hook entry, bringing the total to 2 Stop hooks and 3 hook blocks.
