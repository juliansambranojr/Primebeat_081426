PART 2 - distinct values of the count at each fixed depth
The window spans 2^(r-d-1)..2^r, so its width in b-rungs is
(d+1)*ln2/ln b - a function of d ALONE.  A fixed-width log window
holds a fixed number of rungs up to a floor wobble, so the count
can take at most two values at any fixed depth.
